# web_extension
This repository contains a collection of Chromium-based browser extensions serving various functional purposes.

---

## Purpose of This Repository

The primary objective of this repository is to serve as a centralized hub for creating, maintaining, and testing multiple browser extensions compatible with Chromium engines (including Google Chrome, Microsoft Edge, Brave, and Opera). 

Instead of maintaining isolated repositories for individual tools, this workspace brings together different categories of browser modifications under a unified architecture.

---

## How to Load Any Extension

To run any extension from this repository in your Chromium browser:

1. Navigate to your browser's extension management page:
   *   Chrome / Brave: `chrome://extensions`
   *   Edge: `edge://extensions`
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select the directory containing the `manifest.json` file of the target extension.
